# Ver gen.py para la descripción de los argumentos. Resumen: gen.py N K M MODO, donde M es la
# cantidad de colores distintos (o `perm`) y MODO es uno de si, justo, casi, color, suma, azar
# o igual.
#
# Los modos color y suma generan casos NO donde las poleras no usadas sí son subsecuencia de C,
# para atrapar soluciones que no comparan los multiconjuntos (o que solo comparan la suma).
# Los modos casi y azar generan casos con los mismos colores en C y D, para atrapar soluciones
# que solo comparan los multiconjuntos.

  # K = N

  pequeno ; gen.py 6 6 2 color
  pequeno ; gen.py 8 8 4 suma

  si ; gen.py 100000 100000 1 si
  si ; gen.py 100000 100000 2 si
  si ; gen.py 100000 100000 1000 si
  si ; gen.py 100000 100000 perm si
  igual ; gen.py 100000 100000 50 igual

  color ; gen.py 100000 100000 2 color
  color ; gen.py 100000 100000 100 color
  color ; gen.py 100000 100000 perm color
  suma ; gen.py 100000 100000 3 suma
  suma ; gen.py 100000 100000 perm suma
